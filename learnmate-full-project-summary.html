LearnMate
Agentic AI Coach for Personalized Course Pathways
Problem Statement #12 IBM Cloud Lite IBM Granite 4 · watsonx.ai React + Node.js + Express
Problem & Solution
❌ The Challenge
  • Students overwhelmed by thousands of online courses
  • No guidance tailored to individual skill level
  • No adaptive system that tracks progress over time
  • One-size-fits-all roadmaps don't match real goals
✅ LearnMate's Solution
  • Conversational AI coach powered by IBM Granite
  • Asks focused questions one at a time
  • Never advances until it gets the right answer
  • Generates a personalized roadmap + tracks progress
Key Agentic Behaviour — Persistent Questioning
Example: Student ignores skill-level question repeatedly — bot re-asks every time
Student

hiii

LearnMate

Hi there! I noticed you said "hiii" — what is your current skill level?

1. Beginner   2. Intermediate   3. Advanced

Student

haha ok

LearnMate

Got it! What is your current skill level in Frontend Development?

1. Beginner   2. Intermediate   3. Advanced

LearnMate

Got it — Beginner! 👍 What's your main goal?

1. Get a job   2. Build projects   3. Upskill

The stage never advances until the required answer is received. IBM Granite both generates the natural acknowledgement and extracts the structured value from any phrasing.

5-Stage Agentic Conversation Flow
1
Stage: greeting
👋 Name Collection
Bot greets and asks for the student's name. Keeps asking until a name is detected. IBM Granite extracts first name from any phrasing ("I'm Meera", "call me Sam", "Riya here").
Loops until name is captured
2
Stage: interest_assessment
🎯 Track Selection
Shows 6 numbered learning tracks. Accepts answers by number ("3"), keyword ("frontend"), or natural language ("I like design"). Re-asks if nothing matches.
Granite extraction + number map + keyword fallback
3
Stage: skill_assessment
📊 Skill Level Check
Asks Beginner / Intermediate / Advanced. Accepts numbers, words, or sentences ("I've never coded before" → beginner). Loops until a level is confidently identified.
Granite extraction + regex fallback
4
Stage: goal_collection
🚀 Goal Setting
Asks about the student's main goal (job / projects / upskilling). Single-word noise like "ok" or "lol" is detected and re-asked. Any meaningful sentence is accepted.
Noise detection → re-ask if too short / off-topic
5
Stage: roadmap_generated → in_progress
🗺️ Roadmap + Adaptive Coaching
Personalized roadmap generated instantly from the course catalog. Student then chats freely — bot answers questions, celebrates completions, suggests next steps, and adapts roadmap if they add new tracks.
Full conversation history in every reply Roadmap updates in real time

Technology Stack
🤖
IBM Granite
ibm/granite-4-h-small · via watsonx.ai
The core AI brain of LearnMate. IBM Granite powers every part of the agentic conversation — generating warm, contextual replies, extracting structured values (name, skill level, track, goal) from free-form student input, and producing personalized roadmaps. Used as a mandatory IBM foundation model.
Foundation LLM Reply Generation Value Extraction Roadmap Creation
☁️
IBM watsonx.ai
IBM Cloud Lite · /ml/v1/text/chat API
watsonx.ai is the IBM platform that hosts and serves the Granite model. LearnMate calls the watsonx.ai chat completion API for every student message, passing the full conversation history and a carefully engineered system prompt to maintain agentic stage state across turns.
AI Platform Model Hosting Chat Completions API IBM Cloud Lite
⚛️
React 18 + Vite
Frontend Single-Page Application
The entire LearnMate UI is built with React 18 and bundled with Vite. It provides the Chat panel with stage-aware quick-reply chips, the Roadmap panel with track cards and module progress, and the Profile sidebar showing the student's journey stepper — all updating reactively in real time.
Frontend SPA React 18 Vite Reactive UI
🟢
Node.js + Express
REST API Backend · Port 5000
The backend is a Node.js + Express server that manages the 5-stage agentic state machine, proxies calls to IBM Granite, stores in-memory student sessions, serves the course catalog, and exposes REST endpoints for chat, roadmap generation, and progress tracking.
REST API Agentic State Machine Node.js Express
🔐
IBM IAM
Identity & Access Management · Auto-refresh Bearer tokens
IBM IAM handles all authentication to watsonx.ai. The backend exchanges a long-lived API key for a short-lived Bearer token, caching and auto-refreshing it before expiry. This keeps credentials secure in environment variables and ensures uninterrupted Granite API access throughout the session.
Authentication API Key → Bearer Token Token Auto-Refresh IBM Security
🗂️
In-Memory Session Store
Student State · Conversation History · Roadmap Cache
Each student session is stored in-memory on the server, holding the current agentic stage, collected profile values (name, track, skill, goal), the full conversation history for Granite context, and the generated roadmap with per-course completion status — enabling stateful multi-turn conversations.
Session Management State Machine Conversation History Progress Tracking

How to Run
1
Get IBM Cloud credentials — Sign up free at cloud.ibm.com → create watsonx.ai instance → copy API Key and Project ID
2
Fill backend/.env — Set WATSONX_API_KEY and WATSONX_PROJECT_ID. Model is pre-set to ibm/granite-4-h-small
3
Start backend — npm run dev:backend → API on http://localhost:5000
4
Start frontend — npm run dev:frontend → UI on http://localhost:5173
